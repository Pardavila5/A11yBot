# A11yBot - Contexto obligatorio para futuras sesiones

Cuando el usuario se refiera al proyecto A11yBot, cargar primero estos archivos:

1. `A11YBOT_MEMORY.md`
2. `TFG_ROADMAP.md`
3. `a11ybot-backend/README.md`
4. `a11ybot-frontend/README.md`
5. `a11ybot-backend/A11yBot_CONTEXT.md`

Reglas de uso:
- Tratar estos documentos como la memoria persistente del proyecto.
- Si hay conflicto, priorizar instrucciones directas del usuario.
- Si hay conflicto entre documentos del proyecto, priorizar en este orden:
  1. `A11YBOT_MEMORY.md`
  2. `TFG_ROADMAP.md`
  3. `README.md` de raiz y de cada app
  4. `a11ybot-backend/A11yBot_CONTEXT.md` como contexto academico/funcional
- Si aun hay conflicto, priorizar el codigo fuente actual sobre la narrativa historica.
- Mantener decisiones alineadas con el TFG: claridad, trazabilidad y cambios incrementales.
- Antes de proponer nuevas tareas, revisar el roadmap y el estado actual documentado.
